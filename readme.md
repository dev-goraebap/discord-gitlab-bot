# 깃랩-디스코드 연동 프로젝트

## 프로젝트 개요

깃랩 이슈 관리와 디스코드를 연동하여 팀 전체가 개발 현황을 실시간으로 공유할 수 있도록 자동화

## 현재 상황

- **회사**: hohocompany (SI 업체, 워터폴 방식)
- **버전 관리**: 깃랩 커뮤니티 에디션
- **리파지토리**: 4개 (프론트엔드, 백엔드, 어드민 프론트엔드, 어드민 백엔드)
- **커뮤니케이션**: 디스코드 (회사 자체 서버)
- **현재 프로세스**:
    - 회의록 포럼 채널에 기획자가 작성
    - 개발자들이 회의록 보고 각자 깃랩 이슈 생성
    - 문제는 깃랩 이슈가 디스코드에 공유 안 됨

## 문제점

1. 개발자들은 깃랩에서 이슈 관리
2. 디자이너 및 다른 팀원은 깃랩 안 봄
3. 누가 무엇을 하는지 팀 전체가 파악하기 어려움

## 해결 방안

### 디스코드 채널 구조

**포럼 채널 2개 생성:**

1. **회의록** (기존 유지)
    - 회의 내용 정리
    - 태그: 정기회의, 내부회의, 주간회의 등
    - 댓글: 추가 논의 사항

2. **할일-정리** (신규 생성)
    - 깃랩 이슈 자동 동기화 채널
    - 개발 태스크 현황 공유
    - 팀 전체가 진행상황 확인

### 자동화 흐름

```
회의록 작성 
    ↓
개발자가 깃랩 이슈 생성
    ↓
자동으로 디스코드 '할일-정리' 포럼에 포스팅
    ↓
깃랩에서 댓글/수정/완료 시 디스코드도 자동 업데이트
```

### 동기화 규칙

**깃랩 → 디스코드 (단방향)**

| 깃랩 이벤트 | 디스코드 동작       |
|--------|---------------|
| 이슈 생성  | 포럼 글 생성       |
| 이슈 수정  | 포럼 글 수정 (조용히) |
| 이슈 댓글  | 포럼 댓글 추가      |
| 이슈 닫힘  | 완료 표시         |

**제외 항목:**

- 커밋 메시지 (너무 많아서 스팸 우려)

## 기술 스택

### 필요한 구성요소

1. **디스코드 봇**
    - 이름: 호호봇 (hohocompany 자동화 봇)
    - 권한: 메시지 전송, 스레드 생성, 링크 임베드

2. **Webhook 서버**
    - Node.js + Express
    - Discord.js
    - 회사 서버에 배포

3. **깃랩 Webhook**
    - 이벤트: Issue, Note (댓글)
    - Webhook URL: 서버 주소

### 아키텍처

```
깃랩 이벤트 발생
    ↓
깃랩 Webhook → Node.js 서버
    ↓
서버가 이벤트 파싱
    ↓
Discord.js로 포럼 포스팅
    ↓
디스코드 '할일-정리' 채널에 자동 게시
```

## 기대 효과

1. **투명성 향상**: 전체 팀이 개발 현황 파악 가능
2. **커뮤니케이션 개선**: 디자이너도 개발 진행상황 확인 가능
3. **효율성 증가**: 수동 공유 작업 제거
4. **히스토리 관리**: 회의록-이슈 연결로 맥락 유지

## 주의사항

- 너무 많은 알림은 스팸이 될 수 있음 → 필요한 이벤트만 선택
- 팀원들이 새로운 프로세스에 적응할 시간 필요
- 단계별로 천천히 도입하여 피드백 수렴

## 로컬 테스트 방법

### 1. 환경 설정

1. `.env` 파일 생성 (`.env.example` 참고)
   ```bash
   cp .env.example .env
   ```

2. `.env` 파일에 실제 값 입력
   ```env
   DISCORD_BOT_TOKEN=your_actual_bot_token
   DISCORD_FORUM_CHANNEL_ID=your_forum_channel_id
   PORT=3000
   ```

### 2. 포럼 채널 ID 확인 방법

1. 디스코드 설정 → 고급 → 개발자 모드 활성화
2. 포럼 채널 우클릭 → ID 복사

### 3. 서버 실행

```bash
npm start
```

성공 시 출력:
```
✅ 봇 로그인 성공: 호호봇#1234
🚀 Webhook 서버 실행 중: http://localhost:3000
📡 Webhook URL: http://localhost:3000/webhook
```

### 4. 외부 접근 (ngrok 사용)

로컬 서버를 깃랩 Webhook에서 접근하려면 ngrok 필요:

```bash
# ngrok 설치 (https://ngrok.com/)
ngrok http 3000
```

출력된 HTTPS URL을 깃랩 Webhook에 등록:
```
https://xxxx-xx-xx-xx-xx.ngrok-free.app/webhook
```

### 5. 깃랩 Webhook 설정

1. 깃랩 리파지토리 → Settings → Webhooks
2. URL: ngrok에서 받은 URL + `/webhook`
3. Trigger: `Issue events` 체크
4. Add webhook 클릭

### 6. 테스트

1. 깃랩에서 새 이슈 생성
2. 디스코드 포럼 채널에 자동으로 글이 생성되는지 확인
3. 서버 콘솔에서 로그 확인
